# OpenLumin Test Mod

OpenLumin 渲染库的测试模组。

## 用途

此模组用于验证 OpenLumin 的所有渲染功能，包括：
- 2D 即时模式渲染（矩形、圆角矩形）
- 2D 调度器渲染（形状、文字）
- 3D 世界渲染（线框、填充、坐标轴）
- TTF 字体渲染

## 测试用例

### 2D 渲染（主菜单右上角）
1-3. 纯色矩形（蓝、绿、半透明白）
4-6. 圆角矩形（纯色、渐变、独立圆角）
7-9. Scheduler 图元（圆角矩形、椭圆、矩形）
10-11. TTF 文字（纯色、渐变）

### 3D 渲染（进入世界后）
12. 玩家周围红色线框盒子
13. 玩家周围半透明红色填充
14. RGB 坐标轴（红X、绿Y、蓝Z）

## 构建

```bash
cd openlumin-testmod/fabric-1.21.10
../../gradlew build
```

## 部署

将生成的 jar 文件与 OpenLumin 一起放入 `mods/` 目录。
